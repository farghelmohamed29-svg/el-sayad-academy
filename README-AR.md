# أكاديمية الصياد — نسخة البداية
هذه واجهة أولية مستقلة عن المشاريع القديمة.

## النشر
1. أنشئ مستودع GitHub جديدًا باسم `el-sayad-academy-new`.
2. ارفع ملفات هذه الحزمة إلى جذر المستودع.
3. افتح Settings ثم Pages.
4. اختر Deploy from a branch ثم `main` و`/(root)` واضغط Save.

## تنبيه أمني
هذه النسخة واجهة فقط وليست نظام دخول أو دفع جاهزًا. لا تستخدم كود الطالب وحده لتسجيل الدخول؛ يجب التحقق من هوية الطالب وولي الأمر كلٌ على حدة عبر OTP أو حساب موثّق. يجب فرض انتهاء الاشتراك في قاعدة البيانات/الخادم، لا في JavaScript. لا تضع مفاتيح Supabase السرية أو service_role داخل ملفات الموقع. يجب أن تراجع الإدارة التحويل قبل تفعيل الاشتراك.
