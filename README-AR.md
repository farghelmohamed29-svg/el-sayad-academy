# EL SAYAD ACADEMY — حزمة التطوير الشاملة

## محتويات الحزمة
- واجهة عربية RTL متجاوبة لكل المراحل: ابتدائي، إعدادي، ثانوي.
- اختيار الثانوية العامة أو البكالوريا المصرية عند المرحلة الثانوية.
- لوحة طالب تجريبية بها المواد والوحدات والدروس والاختبارات والنتائج.
- مختبر 3D تفاعلي توضيحي، مع مساحة لربط مجسم خاص بكل درس عملي.
- ملف `supabase-schema.sql` لإنشاء أساس بيانات الملفات الدراسية والمواد والدروس والاختبارات والاشتراكات.

## تشغيل الواجهة محليًا
افتح `index.html` في المتصفح أو انشر الملفات الأربعة على GitHub Pages.

## مهم قبل الاستخدام الحقيقي
هذه الحزمة واجهة وتجهيز قاعدة بيانات وليست منصة إنتاجية مكتملة. لا تحتوي على مكتبة مناهج وزارية كاملة ولا يجوز اعتبار أسماء المواد التجريبية اعتمادًا وزاريًا. يجب إدخال المواد والوحدات من الكتب/القرارات الرسمية للسنة الدراسية المطلوبة ومراجعتها قبل نشرها.

تثبيت الصف والمرحلة في الواجهة وحدها ليس حماية. ملف SQL يجهز قيودًا وسياسات أولية، لكنه يحتاج مراجعة أمنية واختبارًا على مشروع Supabase قبل ربطه بواجهة الطلاب. لا تضع service_role أو أي مفتاح سري في ملفات JavaScript.

## النشر
ارفع ملفات الحزمة إلى مستودع `el-sayad-academy` الجديد فقط، ثم Commit changes. لا ترفع ملفات SQL إلى مجلد الموقع العام؛ نفّذها من SQL Editor في Supabase بعد مراجعتها وأخذ نسخة احتياطية.
