# فهرس المناهج

هذا المجلد مخصص لفهرسة المواد بحسب المرحلة والصف والنظام والسنة الدراسية.

لا تُضاف مادة بوصفها معتمدة وزاريًا إلا بعد تسجيل رابط مصدر رسمي مباشر وتاريخ المراجعة والسنة الدراسية والصف والنظام. تظل المواد غير المراجعة مخفية عن الطلاب.

المراحل المستهدفة: ابتدائي (6 صفوف)، إعدادي (3 صفوف)، ثانوي (3 صفوف) مع تمييز الثانوية العامة والبكالوريا المصرية عند انطباقهما.

الملف الحالي قالب توثيق فقط، وليس قائمة مقررات رسمية.
